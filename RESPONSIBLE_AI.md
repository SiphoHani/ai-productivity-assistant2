# Responsible AI

| Risk | Mitigation in FlowDesk |
|---|---|
| Hallucination | Grounding rules in prompts; "Verify Before Use" section; draft-only labels |
| Privacy | PII detector warns on ID, card, phone, email; no backend; API key kept in browser only |
| Bias / tone | Prompts require inclusive, professional language |
| Over-reliance | Footer and per-result notice: review before use |
| Transparency | Demo/Gemini badge on every result; AI tools disclosed in README |
| Misuse | Chat prompt declines legal, medical, financial decisions |

User guideline: never paste confidential client data into a third-party AI service without authorisation, and comply with POPIA.
